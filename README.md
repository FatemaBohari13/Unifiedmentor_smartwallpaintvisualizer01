# 🎨 WallStudio – Smart Paint Visualizer

## 📌 Project Overview

WallStudio is a smart paint visualization web application designed to help users explore wall colours and designs before purchasing paint. The project allows users to upload room photos, select wall areas, experiment with different colours and patterns, and preview how different paint combinations look in their spaces.

The application provides an interactive workspace where users can create multiple design variations, save their favourite designs, download previews, and estimate the amount and cost of paint required for a wall.

This project focuses on making interior colour selection easier, more visual, and more user-friendly through an interactive and organized interface.

## ✨ Key Features

- **User Authentication:** Includes login and registration functionality, with separate user and administrator roles.
- **Room Image Upload:** Allows users to upload JPG or PNG images of their rooms, with a configurable file size limit.
- **Sample Room Gallery:** Provides sample room images and illustrated room alternatives for users who want to explore the application without uploading their own photos.
- **Wall Selection Tools:** Enables users to select wall areas using a polygon tool or brush and refine selections using an eraser.
- **Interactive Colour Preview:** Allows users to visualize paint colours directly on selected wall areas.
- **Colour Palette:** Includes multiple colour families, such as neutrals, greens, blues, pinks, purples, earthy shades, yellows, warm colours, and teals.
- **Custom Colour Selection:** Lets users choose custom colours using a colour picker or HEX colour codes.
- **Dual-Tone Painting:** Supports two-colour wall combinations with an adjustable split position.
- **Wall Design Patterns:** Offers decorative patterns, including vertical stripes, horizontal stripes, polka dots, and checks.
- **Paint Customization:** Provides adjustable paint opacity and an option to preserve existing wall shadows for a more realistic preview.
- **Design Trials:** Allows users to save and compare different colour combinations for the same room.
- **Saved Designs:** Enables users to save, view, download, and delete their design previews.
- **Paint Calculator:** Estimates the paintable wall area, required paint quantity, number of litres to purchase, and approximate cost based on wall dimensions and paint coverage.
- **Admin Panel:** Allows administrators to manage colour palettes, design patterns, user accounts, saved designs, and application settings.
- **Responsive Interface:** Adapts the workspace layout for different screen sizes, including desktop and mobile devices.
- **Local Data Storage:** Uses browser localStorage to retain application data, including users, colour palettes, settings, activity records, and saved design previews.

## 🎯 Project Objectives

- Simplify the process of choosing wall colours before purchasing paint.
- Help users visualize different colour combinations in their own room photos.
- Provide an interactive way to experiment with wall colours and decorative patterns.
- Enable users to compare, save, and download multiple design ideas.
- Help users estimate paint requirements and potential costs.
- Organize design tools and application features within a clear, accessible interface.
- Apply front-end development principles to create a practical and user-friendly web application.

## 🛠️ Tools & Technologies

- **HTML5:** Structures the application pages, forms, navigation, and content.
- **CSS3:** Provides styling, responsive layouts, visual hierarchy, animations, and interactive states.
- **JavaScript:** Handles application logic, user interactions, authentication flows, wall selection, colour customization, and design management.
- **HTML5 Canvas API:** Renders room images, wall masks, colour overlays, decorative patterns, and design previews.
- **Browser localStorage:** Stores application data locally within the browser.
- **File API:** Supports local image uploads and file reading.
- **Google Fonts:** Uses Bricolage Grotesque and DM Sans for typography.

## 📂 Project Deliverable

A responsive, interactive web application for visualizing wall paint colours and designs.

The project includes a login and registration interface, dashboard, room image gallery, wall selection workspace, colour customization studio, saved designs section, paint calculator, and administrator panel.

The primary deliverable is a functional front-end prototype demonstrating how users can explore interior paint options and manage their design ideas through a single application.

## 💡 Key Learnings

- Building interactive web interfaces using HTML, CSS, and JavaScript.
- Working with the Canvas API to render images and apply colour overlays.
- Implementing wall selection using polygon drawing, brush strokes, and erasing tools.
- Managing application state and persisting data with localStorage.
- Creating reusable rendering and event-handling functions.
- Designing responsive layouts with clear navigation and visual hierarchy.
- Handling image uploads, canvas previews, and PNG exports.
- Implementing basic input validation and user interaction feedback.
- Understanding the importance of usability, accessibility, and error handling in interactive applications.
- Recognizing the limitations of client-side authentication and local browser storage when planning a production-ready application.

## 🚀 Conclusion

WallStudio – Smart Paint Visualizer demonstrates how interactive web technologies can help users make more informed interior colour decisions. By combining room image uploads, wall selection tools, customizable colour palettes, decorative patterns, saved design variations, and paint estimation, the application provides a convenient environment for exploring paint ideas before making purchasing decisions.

The project establishes a foundation for a more advanced paint visualization platform that could later incorporate automatic wall detection, more realistic lighting and texture preservation, cloud-based design storage, and secure server-side authentication.
